**GeoSlicerBase** is a customized application based on [3D Slicer](https://www.slicer.org/), tailored for digital rock analysis. It is built using the [SlicerCAT](https://github.com/KitwareMedical/SlicerCAT) framework, which provides a streamlined process for creating custom applications from 3D Slicer.

## About

This repository contains the source code and build instructions for GeoSlicerBase. The application is designed to provide a focused user experience for geoscientists and engineers working with digital rock imagery. By leveraging the power of 3D Slicer, GeoSlicer offers advanced visualization and analysis tools in a simplified interface.

For more information on SlicerCAT and creating custom 3D Slicer applications, please refer to the official Kitware documentation: [SlicerCAT: Creating Custom Applications Based on 3D Slicer](https://www.kitware.com/slicercat-creating-custom-applications-based-on-3d-slicer/).

## Building GeoSlicer

Instructions for building GeoSlicer from source can be found in the [BUILD.md](BUILD.md) file. The build process is supported on Windows, Linux, and macOS.
